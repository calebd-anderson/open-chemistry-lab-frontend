The Open Chemistry Lab

A Capstone Project in Computer Information Technology

1.

Project Overview

"The Open ChemLab" project was initiated as a Bachelor of Science capstone endeavor. The primary objective is educational, facilitating the discovery of real-world chemical facts through experimentation with various combinations of elements from the periodic table of elements. This project leverages an external RESTful API data service named PubChem.

2.

Architecture & Implementation

The application follows a backend-for-frontend (BFF) architectural pattern. The source code is publicly available on GitHub:

  • Backend - https://github.com/calebd-anderson/open-chemistry-lab-backend
  • Frontend - https://github.com/calebd-anderson/open-chemistry-lab-frontend
3.

Technologies

The project is built using the following technologies:

  • Spring Boot - Web API
  • MongoDB - NoSQL persistence
  • Angular - Frontend framework
  • GSAP - Advanced animations
  • Periodic Table - Interactive periodic table CSS
